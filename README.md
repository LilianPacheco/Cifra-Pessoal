# Cifra Pessoal

Aplicativo Android pessoal de controle financeiro, desenvolvido em Kotlin com Jetpack Compose.

## Executar o projeto

1. Abra esta pasta no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Execute o módulo `app` em um aparelho Android.

O arquivo `local.properties`, credenciais, APKs e dados gerados no aparelho não fazem parte do repositório.
